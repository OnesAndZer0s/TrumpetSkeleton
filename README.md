The Trumpet Skeleton is back, now for 1.20.1

 

Content : 

*   Adds the Trumpet Skeleton entity
    *   Spawns in the world, playing the obnoxious "doot" sound
    *   Killing has a chance to drop the trumpet
    *   The Trumpet Item can be charged up, and plays a "doot" sound, knocking enemies back
